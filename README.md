# KrushiMitr AI

Create a modern, premium, startup-quality AI-powered agriculture web application called "KrushiMitr".

KrushiMitr is an AI Farming Companion that helps farmers detect crop diseases, identify nutrient deficiencies, and receive intelligent fertilizer recommendations simply by uploading a photo of their crop.

The UI should feel like a product built by Apple, Tesla, Notion, and Linear combined—minimal, elegant, highly polished, smooth, modern, and realistic. Avoid cartoonish illustrations and generic templates.

Use:

- React

- TypeScript

- Tailwind CSS

- Modern reusable components

- Beautiful animations

- Clean spacing

- Rounded cards

- Glassmorphism where appropriate

- Soft shadows

- Professional icons

- Fully responsive for desktop, tablet, and mobile.
